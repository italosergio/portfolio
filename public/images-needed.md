# Imagens Necessárias para o Portfolio

Coloque as seguintes imagens na pasta `public/`:

## Imagem de Perfil
- `profile.png` - Sua foto de perfil ✅ (já adicionada)

## Imagens dos Projetos
- `ameciclo.org.png` - Screenshot do site ameciclo.org
- `loaclima.ameciclo.org.png` - Screenshot do site loaclima.ameciclo.org  
- `dom.ameciclo.org.png` - Screenshot do site dom.ameciclo.org
- `lstechdigital.com.br.png` - Screenshot do site lstechdigital.com.br

## Dimensões Recomendadas
- Imagens dos projetos: 800x500px (proporção 16:10)
- Imagem de perfil: 400x400px (quadrada)

## Formato
- PNG ou JPG
- Otimizadas para web (máximo 500KB cada)
