# 🚀 Portfolio Pessoal - Italo

Um portfolio moderno e responsivo desenvolvido com Next.js 15, TypeScript e Tailwind CSS, apresentando animações suaves e um design atrativo.

## ✨ Características

- **Design Moderno**: Interface limpa e profissional com gradientes e animações
- **Totalmente Responsivo**: Otimizado para desktop, tablet e mobile
- **Animações Suaves**: Utilizando Framer Motion para transições elegantes
- **Performance Otimizada**: Built com Next.js 15 e otimizações de performance
- **SEO Friendly**: Metadados otimizados para mecanismos de busca
- **Acessibilidade**: Seguindo as melhores práticas de acessibilidade

## 🛠️ Tecnologias Utilizadas

- **Framework**: Next.js 15
- **Linguagem**: TypeScript
- **Estilização**: Tailwind CSS
- **Animações**: Framer Motion
- **Ícones**: Lucide React
- **Componentes**: Radix UI
- **Linting**: Biome

## 📱 Seções do Portfolio

1. **Hero**: Apresentação inicial com call-to-actions
2. **Sobre**: Informações pessoais e especialidades
3. **Projetos**: Showcase dos principais projetos
4. **Skills**: Habilidades técnicas com barras de progresso
5. **Contato**: Formulário de contato e informações

## 🚀 Como Executar

1. **Clone o repositório**
   ```bash
   git clone https://github.com/seu-usuario/portfolio.git
   cd portfolio
   ```

2. **Instale as dependências**
   ```bash
   npm install
   ```

3. **Execute o servidor de desenvolvimento**
   ```bash
   npm run dev
   ```

4. **Abra no navegador**
   ```
   http://localhost:3000
   ```

## 📝 Personalização

### Informações Pessoais
Edite os seguintes arquivos para personalizar com suas informações:

- `src/components/Hero.tsx` - Informações da seção principal
- `src/components/About.tsx` - Sobre você e especialidades
- `src/components/Projects.tsx` - Seus projetos
- `src/components/Skills.tsx` - Suas habilidades técnicas
- `src/components/Contact.tsx` - Informações de contato

### Cores e Tema
As cores podem ser personalizadas em:
- `src/app/globals.css` - Variáveis CSS customizadas

### Metadados SEO
Atualize os metadados em:
- `src/app/layout.tsx` - Título, descrição e keywords

## 📦 Scripts Disponíveis

- `npm run dev` - Inicia o servidor de desenvolvimento
- `npm run build` - Cria a build de produção
- `npm run start` - Inicia o servidor de produção
- `npm run lint` - Executa o linting do código
- `npm run format` - Formata o código
